How it works
  1. Same task paper to everyone. Pick a suite and models, hit Run — every model answers the exact same prompts, compiled locally in fractions of a second.
  2. Deterministic scoring, no judge model. Every response is run through that suite's fixed checklist — a mechanical pass/fail per criterion, with hand-tuned weights. Nothing subjective, nothing vibe-based.
  3. The score is explained. A score of 36% means "the checks it passed were worth 36 points." Click any task to read the model's raw output and see exactly which checks it hit and missed.
  4. Errors are honest. A missing sample response is recorded as an error cell, never silently as a zero — problems are flagged on the model card.
  5. Free & offline. Built-in sample models, local scoring, nothing to install, no account — the samples run forever at zero cost from this plain Node server. Want live LLMs like Opus or Astra in the same benchmark? Add an API key in .env and those models appear next to the samples; real calls use your key's credits, everything else stays free.
